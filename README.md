# Lansub Stream

Lansub Stream is a free, ad-supported live TV platform built with Flutter.

## Features

- **Live TV Streaming**: Watch live TV channels from around the world.
- **Responsive Design**: Built with Flutter for a seamless experience across devices.
- **Modern UI**: Clean, modern user interface for easy navigation.

## Getting Started

### Prerequisites

- **Flutter**: Ensure you have Flutter installed.
- **Dart**: Ensure you have Dart installed.

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd Lansub-Stream
   ```

2. Install dependencies:
   ```bash
   flutter pub get
   ```

### Running the App

Start the application:

```bash
flutter run
```
